Ato 1: Gerar Especificação (SPEC_JOGO.md) e Disparar Construção em Background

⏱️ 7 Minutos
Paradigma Executivo (Spec-Driven Development): Primeiro peça ao Antigravity para criar a especificação completa do jogo (Passo 1.1). Assim que ele gerar o arquivo SPEC_JOGO.md, dispare o Passo 1.2 para ele programar e testar o jogo completo.
👀 Dica para Iniciantes no Antigravity: Se aparecer um botão azul Proceed / Approve / Accept no chat pedindo confirmação do plano, clique nele para iniciar a construção e mude imediatamente para o Ato 2 enquanto ele trabalha!
Escolha o passo do Ato 1:
Atue como um Arquiteto de Produto e Games. Crie dentro da pasta @tracks/04-flappy-hero/ um arquivo chamado SPEC_JOGO.md contendo a especificação completa para desenvolvermos do zero um jogo web (HTML5 Canvas + CSS + JS puro, zero dependências) estilo Flappy Bird chamado "Flappy Executive Hero: Escapando da Burocracia". A especificação deve detalhar: 1. Mecânica e Física: Gravidade suave e fluida (60fps), espaçamento generoso entre obstáculos e controle por Barra de Espaço / Clique. 2. Obstáculos Bem-Humorados: Os "canos" devem ser barreiras corporativas com rótulos visíveis e divertidos, como "Reunião que podia ser e-mail", "Planilha V14_FINAL.xlsx", "Sistema Legado", "Orçamento Congelado", "Aprovação em 7 Níveis" e "Silo Organizacional". 3. Modo Piloto Automático IA (#btn-autopilot): Um botão na tela que, quando ativado, faz o herói calcular o pulo ideal sozinho para desviar das barreiras (ótimo para demonstração e testes automatizados). 4. Sistema de Avatar Super-Herói: O personagem deve ser desenhado com uma capa de super-herói esvoaçante animada no Canvas e rastro de partículas, suportando carregar a imagem `hero-caricatura.png` / `minha-selfie.png` ou trocar de foto direto na tela (#btn-upload-hero). 5. Efeitos Sonoros Sintetizados (Web Audio API) e placar com medalhas executivas. Apenas crie o documento @tracks/04-flappy-hero/SPEC_JOGO.md primeiro para minha revisão.

Ato 2: Consultar CNPJ + Banco Central ao Vivo via MCP Brasil (Em Paralelo)

⏱️ 14 Minutos
Paradigma Executivo (MCP + Skills + Automations com Governança): Enquanto o Agente 1 constrói o jogo na Aba 1, pressione Cmd + E (Mac) ou Ctrl + E (Win/Linux) para abrir o Agent Manager, inicie uma 2ª conversa e use a Skill radar-mcp-brasil (em .agent/skills/) para cruzar os dados reais do CNPJ da sua empresa com a Selic, IPCA e Dólar de hoje! Ao terminar, clique no botão ⏰ Agendar com /automation para ver o Test Run de Governança (que grava permissões estritas sem curingas em sidecar.json) e abrir o Automations Dashboard (sidecar://dashboard)!
CNPJs de Benchmark: ou digite o seu:
Execute a skill @.agent/skills/radar-mcp-brasil/SKILL.md para o CNPJ 84.429.695/0001-11 (WEG S.A. — caso eu tenha mantido este CNPJ padrão, execute imediatamente para a WEG S.A. sem parar para perguntar): 1. Utilize o servidor MCP Brasil em @mcp/mcp_brasil_zero_deps.py (ex: rodando `python3 mcp/mcp_brasil_zero_deps.py --test-cli 84429695000111`) para consultar em tempo real os dados oficiais deste CNPJ na Receita Federal/BrasilAPI (Razão Social, CNAE Principal, Capital Social, Porte, UF e Quadro Societário) e os indicadores atuais do Banco Central (Taxa Selic, CDI, IPCA e Dólar PTAX). 2. Com base nos dados reais retornados, construa diretamente dentro de @tracks/05-radar-mcp-brasil/ um "Painel Executivo de Inteligência Macroeconômica e Setorial" (sobrescrevendo o index.html de blueprint e criando style.css e app.js) personalizado para esta empresa, com simulador interativo de impacto de Selic, Câmbio e IPCA no setor do CNAE dela. 3. Abra o painel no Browser Sub-Agent para validar e gere um Walkthrough Artifact com o diagnóstico estratégico!

Execute a skill @.agent/skills/gerar-super-heroi/SKILL.md: 1. Localize a minha foto em `tracks/04-flappy-hero/minha-selfie.png` (caso ainda não esteja nessa pasta, busque automaticamente o arquivo mais recente `~/Downloads/minha-selfie*.png` e copie para `tracks/04-flappy-hero/minha-selfie.png`; se não houver nenhum arquivo, gere um Avatar Executivo de Super-Herói padrão). 2. Analise meus traços marcantes na imagem e gere uma versão em estilo Caricatura divertida de Super-Herói / Super-Heroína baseada em mim (salva em `tracks/04-flappy-hero/hero-caricatura.png`). 3. Atualize o jogo em @tracks/04-flappy-hero/ para que o protagonista voando seja o meu Super-Herói Caricatura (com recorte em medalhão/escudo, capa vermelha e dourada esvoaçante animada no Canvas e botão na tela para alternar entre a Caricatura IA e a minha Selfie original!). 4. Abra o jogo no Browser Sub-Agent, faça um voo de teste com o meu Super-Herói desviando das burocracias e gere o Walkthrough com o print final!

Playbook de Segunda-Feira: Criar Seu Workspace Executivo, Automações & Skills

⏱️ Bônus Prático / Segunda-Feira
As 4 Camadas de um Workspace Executivo ("Sala de Guerra Digital"): No Antigravity, uma pasta de projeto combina 1. Rules (AGENTS.md + .agents/rules/ — governança sempre ativa), 2. Skills (.agents/skills/ — playbooks sob demanda com Progressive Disclosure que gastam zero memória em repouso), 3. MCP Servers (.gemini/settings.json + mcp/) e 4. Automations (/automation — agentes agendados com Test Run de permissões estritas em sidecar.json). Escolha um experimento abaixo:
Experimentos Avançados:
Execute a skill @.agent/skills/criar-workspace-executivo/SKILL.md para criar o meu Workspace Executivo de segunda-feira chamado `comite-estrategico-2027` (focado em Planejamento Estratégico, Monitoramento Macroeconômico e Governança de IA — execute imediatamente com estes parâmetros sem parar para perguntar): 1. Crie dentro de `workspaces-executivos/comite-estrategico-2027/` as 4 camadas completas: - Camada 1 (Rules): `AGENTS.md` e `.agents/rules/governanca-setorial.md` com os guardrails de compliance, LGPD e padrão executivo C-Level; - Camada 2 (Skills): `.agents/skills/ritual-semanal-diretoria/SKILL.md` com Progressive Disclosure para preparar a pauta de segunda-feira; - Camada 3 (MCP): `.gemini/settings.json` conectado ao servidor MCP Brasil; - Camada 4 (Automação): `AUTOMACAO_SEGUNDA_FEIRA.md` com o comando `/automation` e o modelo de `sidecar.json` com permissões estritas (`access_grants` calibrados via Test Run). 2. Crie o Cockpit Visual da Sala de Guerra em `workspaces-executivos/comite-estrategico-2027/index.html`, valide no Browser Sub-Agent e gere o Walkthrough!
