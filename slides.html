04 • O Que Vamos Operar Hoje

Os 4 Pilares do Google Antigravity

📋 Missão 1: Planning Mode & Artifacts

Antes de tocar em qualquer arquivo, o agente investiga o contexto e gera um Implementation Plan. Você comenta diretamente no plano para ajustar a rota e aprova.

🌐 Missão 2: Browser Sub-Agent & Walkthrough

O agente abre um navegador real, enxerga a tela, clica nos botões, joga/testa a aplicação sozinho e entrega um Walkthrough com screenshots e vídeo.

⚡ Missão 3: Agent Manager (Cmd/Ctrl + E)

Seu Centro de Comando para coordenar múltiplos agentes trabalhando em frentes paralelas sem bloquear sua atenção.

🛡️ Missão 4: Workspaces, Skills, MCP & Automations

Transforme uma pasta em uma Sala de Guerra Digital com Rules (AGENTS.md), Skills com Progressive Disclosure (.agents/skills/), dados ao vivo (MCP Brasil) e agentes agendados (/automation com Test Run de permissões estritas).

Apoio Rápido • Guia de Bolso

4 Atalhos Essenciais no Google Antigravity 2.0

1. Vincular Pasta & Paralelismo (+ New Conversation)

Use Select Project / ícone de pasta + (New Project ou Create Project → + Add Folder) para vincular pastas, e clique em + New Conversation na barra lateral (ou Cmd/Ctrl + E) para rodar vários agentes em paralelo.

2. Apontar Contexto com @

Use @tracks/04-flappy-hero/, @tracks/05-radar-mcp-brasil/ ou @mcp/mcp_brasil_zero_deps.py para direcionar o foco exato do agente.

3. Comentar no Implementation Plan

Quando o Artifact do plano abrir, passe o mouse sobre qualquer linha para deixar um comentário antes de clicar em Proceed.

4. Acionar Skills & Automations com /

As Skills (.agents/skills/) usam Progressive Disclosure (descobertas sozinhas ou via /radar-mcp-brasil, /criar-workspace-executivo), e você agenda robôs recorrentes com /automation (calibrados via Test Run e gerenciados em sidecar://dashboard).
