Missão 1 — Gerar Sua Sala de Guerra Digital Completa (/criar-workspace-executivo)

Execute a skill @.agent/skills/criar-workspace-executivo/SKILL.md para criar o meu Workspace Executivo de segunda-feira chamado `comite-estrategico-2027` (focado em Planejamento Estratégico, Monitoramento Macroeconômico e Governança de IA para a WEG S.A. — caso eu tenha mantido estes parâmetros padrão, execute imediatamente sem parar para perguntar): 1. Crie dentro de `workspaces-executivos/comite-estrategico-2027/` as 4 camadas completas: - Camada 1 (Rules): `AGENTS.md` e `.agents/rules/governanca-setorial.md` com os guardrails de compliance, LGPD e padrão executivo C-Level; - Camada 2 (Skills): `.agents/skills/ritual-semanal-diretoria/SKILL.md` com Progressive Disclosure para preparar a pauta de segunda-feira; - Camada 3 (MCP): `.gemini/settings.json` conectado ao servidor MCP Brasil; - Camada 4 (Automação): `AUTOMACAO_SEGUNDA_FEIRA.md` com o comando `/automation` e o modelo de `sidecar.json` com permissões estritas (`access_grants` calibrados via Test Run). 2. Crie o Cockpit Visual da Sala de Guerra em `workspaces-executivos/comite-estrategico-2027/index.html`, garanta que o servidor local na porta 8080 esteja ativo, faça uma visita rápida no Browser Sub-Agent para validar e gere o Walkthrough Artifact com o link clicável `http://localhost:8080/workspaces-executivos/comite-estrategico-2027/index.html`!

Missão 2 — Blindar as Regras de Compliance, Alçadas e LGPD (Camada 1: Rules)

Crie uma segunda Skill sob demanda dentro do meu Workspace Executivo em `workspaces-executivos/comite-estrategico-2027/.agents/skills/radar-concorrencia-m-and-a/SKILL.md` (e espelho em `.agent/skills/`): 1. Configure o cabeçalho YAML com `name: radar-concorrencia-m-and-a` e `description: >-` clara para Progressive Disclosure. 2. Defina no protocolo da Skill um passo a passo onde o agente consulta o CNPJ de duas empresas via servidor MCP Brasil (`mcp_brasil_zero_deps.py`), compara Porte, Capital Social, CNAE e sensibilidade à Taxa Selic/Câmbio, e gera um Memorando Executivo de Comparação Competitiva (Benchmarking / M&A). 3. Adicione um card para essa nova Skill no Cockpit `workspaces-executivos/comite-estrategico-2027/index.html` com o prompt pronto para copiar em 1 clique!
